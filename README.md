# 📚 Student Grade Tracker

A Java-based **Student Grade Tracker** developed as part of the **CodeAlpha Java Programming Internship**.

This console-based application helps manage student information and grades and provides a simple way to calculate and display student performance.

## 🚀 Features

* Add student details
* Store student grades
* Calculate average grade
* Display student information
* Evaluate student performance
* Simple console-based interface
* Uses Object-Oriented Programming concepts

## 🛠️ Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
* **Git**
* **GitHub**

## 📂 Project Structure

```text
CodeAlpha_StudentGradeTracker/
│
├── Student.java
├── GradeManager.java
├── Main.java
├── .gitignore
└── README.md
```

### Student.java

Contains the `Student` class and manages student-related information and grades.

### GradeManager.java

Handles grade management and calculations.

### Main.java

Contains the `main()` method and serves as the entry point of the application.

## 💻 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/sandipkumar07-ops/CodeAlpha_StudentGradeTracker.git
```

### 2. Open the Project

```bash
cd CodeAlpha_StudentGradeTracker
```

### 3. Compile the Java Files

```bash
javac *.java
```

### 4. Run the Program

```bash
java Main
```
